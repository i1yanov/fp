Диафильмы для LG webOS 4+ — просмотр диафильмов с сайта diafilmy.su на телевизоре, управление обычным пультом.

  • Разделы сайта: сказки, мультфильмы, стихи и басни, повести и рассказы, учебные, исторические, озвученные, на других языках, DEFA.
  • Сортировка по дате добавления и по году выпуска, рубрикатор по страницам, буквам и годам — даже в разделах на тысячи диафильмов.
  • Случайный диафильм и поиск по названию.
  • Просмотр как в фильмоскопе: кадры плавно «протягиваются» кнопками ▲ ▼, по OK — круговое меню (о диафильме, сохранить, случайный, сначала, выход).
  • Сохранённое — диафильмы в памяти телевизора для просмотра без интернета.
  • Бережно к сайту: один запрос за раз с паузами, а если сайт ограничит доступ — приложение само делает паузу.

Неофициальное приложение для личного использования. Все диафильмы принадлежат их правообладателям и сайту diafilmy.su.
