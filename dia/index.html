Диафильмы

для телевизоров LG на webOS 4 и новее · версия 1.7.0

Установка

  1. Откройте на телевизоре Homebrew Channel.
  2. Если репозиторий ещё не добавлен: «Настройки» → «Добавить репозиторий» → https://i1yanov.github.io/fp/a.json.
  3. Выберите «Диафильмы» → Install. Значок появится в списке приложений.

Управление пультом

  • В списках: стрелки — выбор, OK — открыть, Назад — назад.
  • При просмотре: ▼ следующий кадр, ▲ предыдущий.
  • OK при просмотре — круговое меню: «О диафильме», «Сохранить» / «Удалить», «Случайный диафильм», «Смотреть сначала», «Выйти к списку», в центре — «Закрыть». Стрелки выбирают пункт, OK выполняет.
  • В «Сохранённом» красная кнопка удаляет выбранный диафильм с телевизора.
  • Указка Magic Remote тоже работает: колесо листает кадры, щелчок открывает меню.

Как приложение обращается к сайту

Телевизор не даёт веб-приложениям читать чужие сайты напрямую, поэтому вместе с приложением ставится маленькая фоновая служба. Она запрашивает страницы строго по одной, с паузой 1,5 секунды, и запоминает их на 15 минут. Годы выпуска берутся одним запросом из «Базы диафильмов». Если сайт ответит отказом (403/429/503), служба прекращает обращения на час и приложение показывает, до какого времени пауза. «Сохранённое» при этом работает без сети.

Исходники

dia/src/webos — приложение, dia/src/service — служба, dia/src/build_ipk.sh — сборка пакета: bash dia/src/build_ipk.sh dia/src .

Неофициальное приложение для личного использования. Диафильмы принадлежат их правообладателям и сайту diafilmy.su.
