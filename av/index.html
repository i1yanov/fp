Архив Вещания

для телевизоров LG (webOS 4 и новее) · версия 1.0.0

Приложение для просмотра мультфильмов, фильмов и прослушивания сказок и радиоспектаклей с multiki.arjlover.net. Работает в паре с домашним помощником — маленькой программой на домашнем Linux-сервере (там же, где Samba).

Порядок установки: сначала помощник на сервер (шаг 1), потом приложение на телевизор (шаг 2), потом адрес помощника в настройках приложения (шаг 3).

Зачем нужен помощник

Телевизор не умеет подключаться к SMB-папкам напрямую. Помощник работает на сервере и делает за телевизор всё, что связано с хранением:

  • отдаёт телевизору скачанные файлы из папки Архив Вещания — той же, что использует Android-приложение;
  • сам скачивает мультфильмы в эту папку («Скачать на сервер»), по очереди;
  • хранит историю и места остановки — общие для телевизора, телефонов и планшетов;
  • передаёт онлайн-просмотр через себя, соблюдая правило архива «одно соединение на раздел».

На самом телевизоре не сохраняется ничего, кроме адреса помощника.

Шаг 1. Помощник на сервер

1.1. Узнайте две вещи

ЧтоГде взять
Путь к папке «Архив Вещания» на диске сервера Это папка внутри SMB-шары, которую создало Android-приложение. Путь шары покажет команда
testparm -s 2>/dev/null | grep -E '^\[|path ='
Например, шара [media] с path = /srv/media → папка /srv/media/Архив Вещания. Если Android-приложение ещё не подключали, папка будет создана.
Пользователь Linux Тот же логин, что вы вводите в Android-приложении для SMB. Помощник пишет файлы от его имени, чтобы и Samba, и Android могли их потом изменять и удалять.

1.2. Выполните команду на сервере

Подключитесь к серверу по SSH (на Windows: ssh пользователь@адрес-сервера в PowerShell) и вставьте, подставив свои путь и логин:

curl -fsSL https://i1yanov.github.io/fp/av/install.sh | sudo bash -s -- "/srv/media/Архив Вещания" ivan

Третьим параметром можно задать порт (по умолчанию 8765). Путь обязательно в кавычках — в нём пробел.

Скрипт скачает помощник в /opt/arhiv-veshchaniya, создаст службу arhiv-veshchaniya (запускается сама при включении сервера), откроет порт в ufw, если он включён, и напечатает адрес вида http://192.168.1.10:8765. Запишите его — он нужен в шаге 3.

Нужен Python 3.7+ (есть во всех современных Debian/Ubuntu/Raspberry Pi OS). Ничего дополнительно ставить не нужно.

1.3. Проверьте

Откройте на компьютере в браузере адрес из шага 1.2 с добавкой /api/status, например http://192.168.1.10:8765/api/status. Должен появиться текст с "ok": true и путём к папке.

Шаг 2. Приложение на телевизор

Нужен установленный Homebrew Channel. Если репозиторий ниже уже добавлен (например, для FolderPlex), сразу переходите к пункту 4.

  1. Откройте на телевизоре Homebrew Channel.
  2. Settings → Add repository.
  3. Введите адрес: https://i1yanov.github.io/fp/a.json
  4. В списке приложений выберите Архив Вещания → Install.

Ручная установка: app.arhivveshchaniya_1.0.0_all.ipk (через ares-install или Device Manager).

Шаг 3. Связать телевизор с помощником

  1. Запустите «Архив Вещания» → кнопка Настройки на главном экране.
  2. Введите адрес помощника из шага 1.2 (например, http://192.168.1.10:8765) и имя телевизора (например, «Телевизор в зале» — оно видно в истории на других устройствах).
  3. Нажмите Проверить — должно появиться «Помощник работает (версия …). Папка: …». Затем нажмите Сохранить.

Готово. На главном экране появятся «Загруженное» (общая папка сервера) и «История».

Обслуживание

Состояние службыsystemctl status arhiv-veshchaniya
Журнал работыjournalctl -u arhiv-veshchaniya -f
Перезапускsudo systemctl restart arhiv-veshchaniya
Обновить помощникЕщё раз выполнить команду из шага 1.2 с теми же параметрами
Сменить папку, пользователя или портТо же — команда из шага 1.2 с новыми параметрами (потом обновите адрес в настройках телевизора, если менялся порт)
Удалитьsudo systemctl disable --now arhiv-veshchaniya; sudo rm /etc/systemd/system/arhiv-veshchaniya.service; sudo rm -r /opt/arhiv-veshchaniya
Скачанные файлы и история в папке «Архив Вещания» остаются.

Если что-то не работает

  • «Нет связи с домашним сервером» на телевизоре — проверьте адрес из шага 1.3 в браузере компьютера. Если и там не открывается: systemctl status arhiv-veshchaniya и журнал. Если сервер сменил IP-адрес — закрепите его в роутере (резервирование DHCP).
  • «Нет связи с архивом (HTTP …)» при онлайн-просмотре или скачивании на сервер — проверьте, отвечает ли архив серверу (лучше, когда ничего не играет и не качается):
    python3 /opt/arhiv-veshchaniya/arhiv-server.py --test
    Для каждого из двух наборов заголовков будет ✓ или ✗ с кодом ответа. Подробности ошибок — в журнале: journalctl -u arhiv-veshchaniya -n 50
  • Файлы, скачанные телевизором, не удаляются с Android — помощник запущен не от того пользователя. Повторите шаг 1.2 с логином SMB.
  • Онлайн-просмотр не запускается или ждёт — возможно, с вашего домашнего IP уже идёт соединение с этим разделом (другой телевизор, телефон или загрузка). Архив разрешает одно соединение на раздел для всех устройств дома сразу.

Содержимое принадлежит multiki.arjlover.net. Приложение — для личного семейного использования.
